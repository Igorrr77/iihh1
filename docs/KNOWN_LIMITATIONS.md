# Known limitations / неудобства системы

Ниже список текущих ограничений (на 2026-03-27) и рекомендации.

1. **Нет фоновых интеграционных тестов API провайдеров**
   - Риск: изменения API/скоупов обнаруживаются поздно.
   - Что делать: добавить nightly smoke pipeline с тестовыми токенами.

2. **OAuth token vault хранит шифртекст в БД, но ротация ключа не автоматизирована**
   - Риск: ручной процесс при смене `APP_KEY`.
   - Что делать: добавить команду re-encrypt токенов.

3. **Нет RBAC (один админ)**
   - Риск: неудобно для командной работы.
   - Что делать: добавить роли (owner/operator/viewer).

4. **Нет webhook-пайплайна подтверждения событий у всех провайдеров**
   - Риск: часть данных собирается только polling-моделью.
   - Что делать: расширить `public/webhook.php` под verify-challenge + signature checks.

5. **Сильная зависимость от качества OAuth review и app permissions в кабинетах провайдеров**
   - Риск: часть полей/эндпоинтов недоступна без аппрува.
   - Что делать: вести матрицу scopes per provider и статус review.
