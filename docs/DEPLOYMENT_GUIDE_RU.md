# Развертывание Social Content Harvester на VPS без терминала (для новичков)

> Цель: поставить систему **только через браузер/панель хостинга**, без SSH и без командной строки.

## 1) Что нужно заранее
1. VPS (например Contabo).
2. FastPanel уже установлен хостером.
3. Домен (например `parser.example.com`) направлен на IP VPS.
4. У вас есть архив проекта (`.zip`).

---

## 2) Подготовка сайта в FastPanel
1. Войдите в FastPanel.
2. Откройте раздел **Сайты** → **Создать сайт**.
3. Укажите домен (например `parser.example.com`).
4. Включите SSL (Let's Encrypt) в 1 клик.
5. Убедитесь, что PHP версия = **8.2+**.

---

## 3) Загрузка файлов проекта (без терминала)
1. В FastPanel откройте **Файловый менеджер**.
2. Перейдите в папку сайта (обычно `www/domain/public_html` или аналог).
3. Загрузите zip-архив проекта.
4. Нажмите **Распаковать**.
5. Проверьте, что в корне сайта есть файл `install.php`.

---

## 4) Запуск веб-установщика
1. Откройте в браузере:  
   `https://ваш-домен/install.php`
2. Заполните поля:
   - `APP_URL`: `https://ваш-домен`
   - MySQL (`DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASS`)
   - `ADMIN_EMAIL`, `ADMIN_PASSWORD`
   - OAuth Client ID/Secret для нужных соцсетей (можно частично)
3. Нажмите **Установить**.
4. После успеха удалите `install.php` в файловом менеджере (важно для безопасности).

---

## 5) Настройка cron без терминала
1. В FastPanel откройте раздел **Планировщик задач (Cron)**.
2. Добавьте задачу:
   - Интервал: `* * * * *` (каждую минуту)
   - Команда (укажите реальный путь в панели):  
     `/usr/bin/php /path/to/site/public/worker.php`
3. Сохраните.

> Если путь к php в панели другой — используйте путь из FastPanel (обычно отображается в настройках cron).

---

## 6) Первый вход и проверка
1. Откройте: `https://ваш-домен/public/login.php`
2. Войдите под `ADMIN_EMAIL` / `ADMIN_PASSWORD`.
3. Откройте страницу: `https://ваш-домен/public/doctor.php`
4. Убедитесь, что проверки в статусе **OK**.

---

## 7) Минимальные настройки безопасности
1. SSL включен и `APP_URL` начинается с `https://`.
2. Сложный пароль админа.
3. Не храните client secret в заметках/чатах.
4. Удалите `install.php`.
5. Ограничьте доступ к админке по IP через FastPanel (если возможно).

---

## 8) Что делать, если не запускается
1. Смотрите `doctor.php` — там список проблем.
2. Проверьте правильность MySQL доступа.
3. Проверьте, что сайт работает на PHP 8.2+.
4. Проверьте, что cron включен.
5. Проверьте, что OAuth Redirect URI в кабинетах соцсетей совпадает **символ в символ**.
